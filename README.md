# DopaDroid Gradle Plugin

DopaDroid Gradle Plugin, an enhanced Android Gradle Plugin for building Android applications, with added support for reassembling Smali files.

This repository contains the forked `gradle-core` module (based on Android Gradle Plugin 9.5.0 / Android Studio `studio-2026.2.2`).

- Plugin ID: `dev.dopadroid.application`
- Maven coordinates: `dev.dopadroid.tools.build:gradle`
